## [0.1.3] — Theme baseline (pre-documentation)

Existing theme features at documentation start:

- WordPress 7.0 FSE block theme with Amethyst Monolith design system
- Homepage patterns: Hero, About, Projects, Stack, Testimonials, Contact
- Fixed glass header with scroll transparency and responsive navigation
- Query Loop project cards (`project` CPT via companion plugin)
- Contact form REST endpoint with security controls
- NIKWEB.EU branding, mobile hamburger menu, and centered overlay navigation
